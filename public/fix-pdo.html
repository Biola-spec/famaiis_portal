🔧 Fix PDO MySQL Driver Issue

Current Status:

✅ PDO MySQL driver is ENABLED

❌ PDO MySQL driver is NOT ENABLED

How to Fix (Choose ONE method):

Method 1: Using Administrator PowerShell (Recommended)

Step 1: Open PowerShell as Administrator

Step 2: Run this command:

(Get-Content "C:\Program Files\php-8.4.10-Win32-vs17-x64\php.ini") -replace '^;extension=pdo_mysql', 'extension=pdo_mysql' | Set-Content "C:\Program Files\php-8.4.10-Win32-vs17-x64\php.ini"

Step 3: Restart the Laravel server:

Ctrl+C (to stop), then php artisan serve (to start)

Method 2: Manual Edit

Step 1: Open this file in Notepad as Administrator:

C:\Program Files\php-8.4.10-Win32-vs17-x64\php.ini

Step 2: Find this line (around line 934):

;extension=pdo_mysql

Step 3: Change it to (remove the semicolon):

extension=pdo_mysql

Step 4: Save the file

Step 5: Restart the Laravel server

Method 3: Use XAMPP's PHP Instead

Step 1: Enable PDO MySQL in XAMPP's php.ini:

C:\xampp\php\php.ini

Step 2: Find and uncomment (remove ;):

extension=pdo_mysql

Step 3: Use XAMPP's PHP to run the server:

C:\xampp\php\php.exe artisan serve
